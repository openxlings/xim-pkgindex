# k6

Grafana k6 is a modern load testing tool built with Go and JavaScript. Provides the `k6` CLI command; status `stable`.

- Upstream: https://github.com/grafana/k6 (`AGPL-3.0`)
- Namespace: `xim`
- Platforms: `linux` (`x86_64`, `aarch64`), `macosx` (`x86_64`, `aarch64`), `windows` (`x86_64`). `windows/aarch64` is omitted because upstream `v2.4.0` does not publish a Windows ARM64 archive.

## Source

- Tier: official repository release (`grafana/k6` GitHub Releases)
- GLOBAL: `https://github.com/grafana/k6/releases/download/v${version}/k6-v${version}-<os>-<arch>.(tar.gz|zip)`
- CN: none yet (`ci = { mirror = true }`)
- Checksums: verified against upstream `k6-v2.4.0-checksums.txt` and confirmed with `sha256sum -c` on all five downloaded archives.
- Auto-update: yes (`extensions.autoupdate` using `${tag}` / `${version}` for all five platform/arch targets).

## Linking

- Linux (`amd64` and `arm64`): statically linked Go ELF executables (`readelf -d` shows no dynamic section, zero `DT_NEEDED`; `ldd` reports not a dynamic executable). Declares no `xim:glibc` runtime dependency.
- Windows (`amd64`): PE32+ executable importing only `kernel32.dll` (no `VCRUNTIME140.dll`), so no `xim:vcruntime` runtime dependency is needed.

## What the hooks do

- `install`: delegates to `xim.pkgindex.payload.unpack` (moving `k6-v<ver>-<os>-<arch>/` or extracting `.zip` via `System32\tar.exe --strip-components=1` on Windows) and verifies `k6` / `k6.exe` with `payload.require`.
- `config`: registers `k6` with `xvm.add("k6", { bindir = pkginfo.install_dir() })`.
- `uninstall`: removes `k6` via `xvm.remove("k6")`.
- System impact: none.

## Verification

- Static & isolation pytest suites, repo-wide checks, quoting lint, and CI shell checks run on Linux `x86_64`.
- End-to-end `xlings` install, `k6 version`, `k6 inspect`, `verify` pytest, and removal verified on Linux `x86_64`.
- Not run locally: `linux/aarch64`, `macosx/x86_64`, `macosx/aarch64`, `windows/x86_64` (covered by CI / verified via archive inspection and checksums).
